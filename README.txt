N Nova — концепт «тихой» социальной сети: меньше шума, больше осмысленного контента, творчества и сообществ по интересам. Проект представляет собой статический фронтенд-прототип с несколькими страницами и интерактивными элементами на чистом JavaScript.

Слоган проекта: A quieter kind of social.

Описание
N Nova — учебный/демонстрационный прототип социальной платформы. В нём реализованы основные сценарии: лендинг, лента публикаций, собственный профиль пользователя и профиль другого пользователя. Интерфейс выполнен в минималистичном стиле с акцентным бирюзовым цветом, шрифтом Inter и адаптивной навигацией.

Проект не требует сборки и запускается как набор HTML-файлов. Все данные — статические, без backend, авторизации и сохранения состояния между перезагрузками.

Технологии
HTML5 — разметка страниц.

Tailwind CSS via CDN — стилизация и адаптивная вёрстка.

JavaScript — интерактив: табы, лайки, комментарии, модальное окно, подписка.

Google Fonts — шрифт Inter.

Unsplash — демонстрационные изображения.

Кастомная палитра Tailwind:

brand: {

}

Запуск
Так как проект статический, его можно открыть напрямую в браузере:

text
Открыть index.html
Либо запустить локальный сервер из папки проекта:

bash
python3 -m http.server 8000
После этого открыть:

text
http://localhost:8000/index.html
Для загрузки Tailwind CSS, шрифтов и изображений требуется интернет-соединение, поскольку используются CDN и внешние ссылки Unsplash.

Ограничения прототипа
Нет backend и базы данных.

Нет реальной авторизации и регистрации.

Данные не сохраняются после перезагрузки страницы.

Лайки, комментарии, подписка и редактирование профиля работают только на клиенте.

Изображения и контент — демонстрационные.

Tailwind подключён через CDN, что подходит для прототипа, но не для production-сборки.
